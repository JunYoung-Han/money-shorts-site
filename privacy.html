개인정보처리방침

시행일: 2026년 10월 30일

이 방침은 유튜브 채널 "몇시간짜리"(@몇시간짜리)의 운영 도구(이하 "이 앱")가 구글 계정 데이터를 어떻게 다루는지 설명합니다.

1. 이 앱의 용도와 사용자

이 앱은 채널 주인 본인만 사용하는 개인 도구입니다. 채널 주인이 자기 구글 계정으로 로그인해 다음 작업에만 씁니다.

  • 본인 유튜브 채널에 영상 업로드, 예약 공개 설정, 썸네일 지정, 업로드한 영상의 설정 확인
  • 본인 채널의 유튜브 분석(조회수 등 통계) 조회
  • 본인 구글 시트에 제작·업로드 기록 작성

이 앱은 일반 사용자에게 제공되지 않으며, 다른 사람이 로그인해 쓰는 서비스가 아닙니다.

2. 모으는 정보

이 앱은 다른 사람의 개인정보나 데이터를 모으지 않습니다. 시청자, 구독자, 댓글 작성자 등 제3자의 정보도 수집하지 않습니다. 이 앱이 다루는 것은 위 작업에 필요한 채널 주인 본인의 유튜브 채널·영상 정보, 채널 통계, 본인 시트의 내용뿐입니다.

3. 저장과 보안

구글 로그인 후 받은 인증 토큰은 채널 주인의 개인 PC에만 저장됩니다. 토큰과 계정 데이터는 외부 서버로 보내지 않고, 이 웹사이트에도 저장하지 않습니다.

4. 제공과 공유

구글 계정에서 받은 데이터는 누구에게도 판매·제공·공유하지 않으며, 광고나 위 용도 외의 목적에 쓰지 않습니다. 이 앱의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 접근 권한 철회와 삭제

이 앱의 접근 권한은 구글 계정의 서드파티 앱 접근 관리에서 언제든 철회할 수 있습니다. PC에 저장된 토큰을 지우면 이 앱은 더 이상 계정에 접근하지 못합니다.

6. 방침 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다.
